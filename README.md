# Сайт стоматологии «Идеал» (Уфа), врач Хамзина А. Ф.

Пробный макет нового сайта. Основной вариант пока: `index.html`.

## Что здесь
- `index.html` — главная (вариант 1, по макету: тёмно-синий и бежевый)
- `otzyvy.html` — страница «Что говорят пациенты» (рейтинг и ссылка на ProDoctorov, тексты отзывов не копируем)
- `solo.html` — запасной вариант в стиле шаблона Solo Dentist (Framer)
- `images/` — фото врача, фото приёма, логотип
- `source/` — исходники макета из Claude (формат `.dc.html`), нужны только чтобы продолжить правки там

Сайт статичный: открыть `index.html` в браузере, ничего собирать не нужно.
